# vcalc — учебный TCP-сервер для вычислений

Серверная часть курсовой работы. Принимает по TCP-соединению набор векторов чисел, вычисляет для каждого вектора произведение элементов и возвращает результат клиенту. Доступ к вычислениям — после аутентификации по логину и паролю (соль + хеш), пользователи хранятся в файле базы данных.

## Стек

- Язык: C++14
- Сборка: Makefile
- Сеть: POSIX sockets (`sys/socket.h`, `unistd.h`), Linux
- Работа с аргументами: `getopt_long` (`getopt.h`)
- Хранение пользователей: файл БД (`vcalc.conf` по умолчанию)
- Логирование: собственный класс `Logging` в файл (`vcalc.log` по умолчанию)

## Требования

- Linux (используются POSIX-сокеты и `getopt_long`)
- Компилятор с поддержкой C++14 (g++ ≥ 5.1 / clang++ ≥ 3.4)

## Установка и сборка
```bash
git clone https://github.com/ArthesDarkX/Server_BYS.git
cd Server_BYS
make
```

## Запуск

```bash
./vcalc
```

С параметрами:

```bash
./vcalc -p 33333 -d ./data/vcalc.conf -l ./logs/vcalc.log
```

### Параметры командной строки

| Опция | Длинная | Аргумент | По умолчанию | Описание |
| :--- | :--- | :--- | :--- | :--- |
| `-h` | `--help` | — | — | Показать справку |
| `-p` | `--port` | порт (0–65535) | `33333` | Порт сервера |
| `-d` | `--database` | путь | `vcalc.conf` | Файл базы данных пользователей |
| `-l` | `--log` | путь | `vcalc.log` | Файл лога |

Некорректные значения (нечисловой порт, порт вне диапазона, неизвестная опция) приводят к исключению с сообщением об ошибке и кодом возврата `1`.

## Протокол взаимодействия

Соединение: TCP, клиент подключается к `host:port`.

1. **Аутентификация**
   - Клиент → сервер: логин, 4 байта.
   - Сервер → клиент: соль (строка). Если пользователь не найден — сервер отправляет `ERR` и закрывает соединение.
   - Клиент → сервер: хеш пароля, 64 байта.
   - Сервер → клиент: `OK` при успехе или `ERR` при ошибке.
2. **Вычисления**
   - Клиент → сервер: `uint32` — количество векторов (≤ `MAX_VECTORS`).
   - Для каждого вектора:
     - Клиент → сервер: `uint32` — размер вектора (≤ `MAX_SIZE_VECTOR`),        затем элементы `uint16` по порядку.
     - Сервер → клиент: `uint16` — результат.

## Ограничения и допущения

- `MAX_VECTORS` и `MAX_SIZE_VECTOR` ограничивают входные данные, чтобы защититься от слишком больших запросов.
- Произведение считается в `uint16_t` с насыщением: если результат превышает `65535`, возвращается `65535`. Если в векторе есть `0`, результат — `0`. Пустой вектор даёт `0`.
- Сервер обрабатывает соединения последовательно.
